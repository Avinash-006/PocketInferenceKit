# Roadmap

## v0.1.0

- LiteRT-LM chat with lifecycle-managed native handles, backend fallback, and cancellable streaming.
- Verified model catalog, resumable download and import paths, and local cache management.
- Structured tool registration and a Material 3 sample with clock and arithmetic tools.
- Compose state and progress helpers plus a binary API baseline.

## Candidate follow-ups

- Measure device RAM, time to first token, throughput, and cancellation on a reproducible Android device matrix.
- Review more compact and tool-capable model revisions for the catalog.
- Explore structured model output and a separate embeddings API.
- Add integration examples for dependency injection and app lifecycle ownership.
- Explore a Kotlin Multiplatform surface after backend and binary constraints are understood.

Discuss changes to public types in a GitHub issue before submitting an implementation.
