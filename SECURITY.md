# Security policy

The latest 0.1.x release receives security fixes. Older snapshots should be upgraded to a supported release.

Use GitHub's private vulnerability reporting option when available. If it is unavailable, open a public issue titled “Security contact requested” so the maintainer can arrange a private channel. Keep reproduction details, credentials, and private model files out of the public issue.

Include the SDK version, Android version, affected component, and a minimal reproduction in the private report. The maintainer will coordinate disclosure and a fix when appropriate.
