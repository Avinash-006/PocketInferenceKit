## [0.1.0] - 2026-11-23

### Added

- Kotlin Android wrappers for on-device LiteRT-LM engine loading, backend fallback, and cancellable streaming chat.
- Verified Qwen model catalog, WorkManager downloads with resumable byte ranges, and local import and cache APIs.
- Validated structured tool calls with bounded continuation, plus clock and calculator examples.
- Compose state and download-progress helpers and a Material 3 demo app.
- CI for build, lint, JVM tests, and public ABI checks.
